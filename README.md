# Expediente de Adecuación al Esquema Nacional de Seguridad (ENS)

Este repositorio contiene la documentación necesaria para la adecuación y cumplimiento del **Esquema Nacional de Seguridad (ENS)** de acuerdo con el **Real Decreto 311/2022**.

## Guía de Uso del Expediente

Para mantener un expediente profesional, sigue esta organización:

### 📂 01_Politica_y_Estrategia
Contiene la **Política de Seguridad de la Información (PSI)**. Es el documento de nivel superior que debe ser aprobado por la dirección.
*   *Estado actual:* Pendiente de migrar desde el escritorio.

### 📂 02_Organizacion_y_Responsabilidades
Documentos que definen quién es quién: Responsable de la Información, Responsable del Servicio y Responsable de Seguridad. Incluye actas de nombramiento.

### 📂 03_Analisis_y_Gestion_de_Riesgos
Aquí se guarda la metodología de análisis de riesgos y los informes resultantes (ej. exportaciones de PILAR).
*   **Mandatorio** para categorías Media y Alta.

### 📂 04_Cuerpo_Normativo
La "letra pequeña" de la seguridad:
*   **Normas:** Reglas generales (ej. uso de correo, contraseñas).
*   **Procedimientos:** Pasos a seguir (ej. cómo se hace un backup, cómo se da de alta a un usuario).
*   **Instrucciones Técnicas:** Detalles de configuración (ej. cómo está configurado el Firewall).

### 📂 05_Declaracion_de_Aplicabilidad
El documento **SoA (Statement of Applicability)**. Es una tabla que lista los 75 controles del Anexo II del ENS y justifica cuáles aplican y cómo se cumplen.

### 📂 06_Evidencias_y_Registros
Pruebas de que lo anterior se cumple: logs, informes de escaneo de vulnerabilidades, actas de reuniones de seguridad.

### 📂 07_Plan_de_Adecuacion
El cronograma de tareas pendientes para alcanzar el cumplimiento total.

---

## Siguientes Pasos Recomendados

1.  **Definir la Categoría:** ¿El sistema es Categoría Básica, Media o Alta?
2.  **Completar la PSI:** Adaptar el borrador "CONFORMIDAD CON EL ESQUEMA NACIONAL DE SEGURIDAD.docx" y guardarlo en `01_Politica_y_Estrategia`.
3.  **Elaborar el SoA:** Es la pieza central que falta para un expediente profesional.
