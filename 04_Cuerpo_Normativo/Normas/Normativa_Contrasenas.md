# Normativa de Contraseñas y Autenticación - INNOVATEK

## 1. Objetivo
Garantizar que el acceso a los sistemas de INNOVATEK se realice mediante mecanismos de identificación y autenticación robustos.

## 2. Requisitos de Contraseñas
Todas las contraseñas deben cumplir con los siguientes mínimos:
*   **Longitud mínima:** 12 caracteres.
*   **Complejidad:** Debe incluir mayúsculas, minúsculas, números y caracteres especiales.
*   **No reutilización:** No se podrán utilizar las últimas 5 contraseñas anteriores.
*   **Confidencialidad:** Queda estrictamente prohibido compartir contraseñas o anotarlas en lugares visibles.

## 3. Doble Factor de Autenticación (MFA)
El uso de **MFA es obligatorio** para todos los servicios críticos:
*   Acceso al correo electrónico (Microsoft 365 / Google Workspace).
*   Acceso a la plataforma de automatización n8n.
*   Acceso a consolas de administración cloud (Azure, AWS, GCP).

## 4. Gestión de Credenciales
Se recomienda el uso de un gestor de contraseñas corporativo para almacenar credenciales de forma segura y cifrada.
