# Normativa de Contrasenas y Autenticacion - INNOVATEK

## 1. Objetivo
Garantizar que el acceso a los sistemas de INNOVATEK se realice mediante mecanismos de identificacion y autenticacion robustos.

## 2. Requisitos de Contrasenas
Todas las contrasenas deben cumplir con los siguientes minimos:
*   **Longitud minima:** 12 caracteres.
*   **Complejidad:** Debe incluir mayusculas, minusculas, numeros y caracteres especiales.
*   **No reutilizacion:** No se podran utilizar las ultimas 5 contrasenas anteriores.
*   **Confidencialidad:** Queda estrictamente prohibido compartir contrasenas o anotarlas en lugares visibles.

## 3. Doble Factor de Autenticacion (MFA)
El uso de **MFA es obligatorio** para todos los servicios criticos:
*   Acceso al correo electronico (Microsoft 365 / Google Workspace).
*   Acceso a la plataforma de automatizacion n8n.
*   Acceso a consolas de administracion cloud (Azure, AWS, GCP).

## 4. Gestion de Credenciales
Se recomienda el uso de un gestor de contrasenas corporativo para almacenar credenciales de forma segura y cifrada.
